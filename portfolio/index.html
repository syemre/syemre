Module — Technischer Deep Dive

AntiFly.lua

ModuleScript

Multi-Layer Fly-Hack-Detection mit 3 Trigger-Bedingungen: Airtime (>1.5s), Hover-Detection (8 Frames) und unnatürliches Aufsteigen (>18 vel). Nutzt einen 2-stufigen Raycast-Ansatz — erst Fast-Path Single-Ray, bei Verdacht Multi-Ray mit 4 Offset-Punkten für Kanten und schmale Plattformen. Checks werden über einen Staggered Heartbeat Loop (max. 3 Spieler pro Frame) verteilt um Performance zu schonen. Nach 2 Violations → Kick.

Staggered Loop Multi-Raycast AllowFly Whitelist Post-Climb Grace TempBypass API

AntiGodMode.lua

ModuleScript

4-Layer Humanoid-Validator: MaxHealth-Manipulation (Reset auf 100), Health Overflow (Health > MaxHealth + Toleranz), Health-Snapback-Detection (Health springt nach Schaden sofort hoch — 3 Snapbacks = Flag) und WalkSpeed/JumpPower-Abuse (>100 WalkSpeed oder JumpPower). Korrigiert illegale Werte sofort via pcall und zählt Violations bis zur Bestrafung via SaveSTSComm.punishPlayer().

MaxHealth Reset Snapback Detection WalkSpeed Guard SaveSTSComm API

AntiDex.lua

ModuleScript

Echtzeit-Scanner der CoreGui-Hierarchie und des Spieler-Arbeitsspeichers gegen Dark Dex, Game-Tree-Dumper und GUI-Scraper. Erkennt unbekannte ScreenGuis und suspicious Instance-Namen die typisch für Executor-Tools sind.

CoreGui Scanner Memory Inspection GUI Scraper Detection

AntiIY.lua

ModuleScript

Detection-Engine gegen Infinity Yield Command Bar-Hooks, globale Environment-Injektionen und Executor-Script-Calls. Überwacht verdächtige _G-Einträge und RemoteEvent-Aufrufe die typisch für IY-Nutzer sind.

Command Bar Detection _G Hook Scanner Remote Monitoring

AntiFling.lua

ModuleScript

Physik-Validator der AssemblyLinearVelocity und angulare Rotation überwacht. Erkennt Fling-Exploits durch abnorme Velocity-Spitzen bei anderen Spielern in der Nähe. Spinbot-Erkennung via Rotationsgeschwindigkeit über mehrere Frames.

Velocity Solver Angular Momentum Spinbot Detection

AntiAbuse.lua

ModuleScript

Server-seitiger Behavior-Monitor der Animations-Abuse, Griefing und unauthorisierte Character-State-Manipulation erkennt. Überwacht Animations-Trigger-Frequenz, illegale Emote-Loops und Spam-Patterns. Integriert in das SaveSTSComm Flag-System.

Anim Frequency Guard Behavior Monitor Grief Detection

AntiWeapon.lua

ModuleScript

Weapon-Payload-Validator der alle eingehenden RemoteEvent-Damage-Calls vom Carbon SEngine auf dem Server validiert. Prüft Auth-Token (if not Auth or Auth ~= "Auth" then player:Kick()), verhindert Waffen-Spawning, Infinite-Ammo, Rapid-Fire-Hacks und modifizierte Schadensvalues. Integriert direkt mit dem Carbon SEngine Damage-Event-System.

Auth-Token Validation Damage Event Guard Carbon SEngine Integration Ammo State Tracking Rapid-Fire Detection

TvTV2 Matchmaker

TvTV2_Matchmaker (Script)

Live

Vollständiges Team-Vs-Team-System mit Opt-In-Prompt via RemoteEvent (OptInPrompt:FireClient()), 20-Sekunden-Sammelfenster, und anschließendem Private-Server-Teleport via TeleportService:ReserveServer(ARENA_PLACE_ID). Überträgt Team-Zuordnung, Match-ID und Spieleranzahl als TeleportData in den Arena-Server. Unterstützt /tvt random, /tvt [team1] [team2] und Auto-Matchmaking. Blacklist für nicht-kampffähige Teams (Zivilist, Regierung, etc.). Berechtigung über Gruppen-Rang ≥ 252 oder DivisionCommanderRank-Attribut.

ReserveServer TeleportData Payload Opt-In System Team Blacklist Rang-Auth

Money & Paycheck System

MoneyCore + MoneyAPI + PaycheckAPI

MoneyCore initialisiert beim PlayerAdded eine CashData-Folder mit einem IntValue (Cash), wartet auf das ProfileStore-Profil und bridget via cash.Changed:Connect() alle Änderungen direkt zurück in profile.Data.Money. MoneyAPI (ModuleScript) stellt AddMoney(), RemoveMoney() und SetMoney() bereit. PaycheckAPI managed automatische Lohnauszahlungen. Admin-Commands via Cmdr: GiveMoney, RemoveMoney, SetMoney, ResetMoney.

ProfileStore Bridge MoneyAPI Module Paycheck Subservice Changed:Connect Bridge

Rang-System

RankHandler + TeamRankHandler + DivisionRankHandler

Dreistufiges Rang-Framework: RankHandler verwaltet Basis-Ränge, TeamRankHandler manages team-interne Beförderungen und DivisionRankHandler + ArmyRankHandler die Divisions-Hierarchie. Cmdr-Commands für Admins: GiveDivTeam, RemoveDivTeam, RemoveTeam. Rang-Checks nutzen direkt die Roblox Group API (player:GetRankInGroup()) kombiniert mit String- und Attribut-basierten Division-Commander-Rollen.

Group Rank API 3-Layer Hierarchy Division Commander Cmdr Integration

Carbon SEngine Integration

Carbon_SEngine (Script) + Web_Config

Server-seitige Integration des Carbon Gun-Framework. Verarbeitet alle Remote-Events: EquipEvent, DamageEvent, HitEvent, KillFeedEvent, ExplosiveEvent. Jeder Call validiert ein Auth-Token — fehlt es → Kick mit ROBLOX-Logeintrag. Managed server-seitige Ammo-State-Storage per Spieler/Waffe, Holster-Models, Attachment-System und Ragdoll-Trigger bei Tod. Kill-Feed wird über alle Clients via FireAllClients gestreamt. Webhook-Post bei Kill via HttpService.

Auth-Token Guard Ammo State Storage Kill Feed Broadcast Ragdoll Module Webhook Integration

Robbery & Hacking System

RobberySystems — LockerManager + HackingManager

Zweiteiliges Robbery-System: LockerManager verwaltet den Zugang zu gesicherten Bereichen (Spinde, Waffenräume), HackingManager steuert die Hacking-Mechanik bei Überfällen. Verbindet Workspace-Objekte mit Server-Logik über ProximityPrompts und RemoteEvents.

ProximityPrompts Locker Access Control Hacking Mechanic

Riot System

SSS@Riot System — Riot Script + Config

Event-System für Server-weite Riot-Events. Admin-Command /riotstart via Cmdr triggert den Riot Script mit konfigurierbarem Config-Modul. Steuert Team-Zustände, Spawn-Punkte und Event-Ablauf über Workspace-Riot-System-Folder.

Cmdr Command Server-wide Event Config Module
